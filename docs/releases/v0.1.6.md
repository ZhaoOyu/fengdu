风度首次在 GitHub 发布。现在可以在 Mac 菜单栏查看风扇状态，需要时输入一个转速，或让风扇跟随温度自动调整。

- **点选即切换**：系统自动、手动转速、温度曲线三种模式。手动输入 RPM 后按回车即可应用，随时可以交回给系统。
- **菜单栏由你选**：圆环或跑道可显示目标转速占比。点击风扇和数字预览，可只保留其中一项，也可同时显示。手动时显示目标转速，自动时显示 AUTO。
- **看清实际效果**：点开原生面板，查看芯片温度和每个风扇的实测转速。只查看无需授权；调节时才请求管理员权限。

**安装**：适用于有内置风扇的 Apple Silicon Mac，需 macOS 14 或更新版本。下载下方的 **Fengdu-0.1.6-macos-arm64.dmg**，打开后将应用拖入「应用程序」。无需额外安装辅助工具。安装包未经过 Apple 公证，可用随附的 SHA256SUMS.txt 核验文件。
